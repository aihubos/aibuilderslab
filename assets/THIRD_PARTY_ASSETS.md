# 외부 도구 표기와 출처

## v1 적용 원칙

공개 사업·교육 소개 페이지라는 성격을 고려해, 사용 범위가 명확하지 않은 외부 로고 파일은 번들에 포함하지 않았습니다. 교육 도구 영역에서는 공식 명칭을 텍스트로만 표시합니다. AI 빌더스 랩 자체 로고와 심볼은 사용자가 제공한 원본을 사용합니다.

## 안내

외부 명칭은 교육 도구를 설명하기 위한 것이며 후원, 인증 또는 공식 제휴를 의미하지 않습니다. 향후 사용 권한이 확인된 공식 로고를 추가할 때는 원본 비율과 여백을 유지하고 이 문서에 파일명과 출처를 기록합니다.
